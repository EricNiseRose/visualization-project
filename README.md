# Visualization project

Интерактивный дашборд продаж ЖК «Москва-Берег» за март–сентябрь 2026 года. Учебный проект по визуализации данных.

**Открыть дашборд:** https://ericniserose.github.io/visualization-project/

## Возможности

- Карта квартир: цена за квадратный метр, этаж, площадь, комнатность и статус продажи. Подсказки включают продавшего менеджера.
- Фильтры по корпусу, комнатности, статусу и диапазону площади.
- Сравнение комнатности и корпусов по количеству и долям: продажи без скидки, со скидкой, остаток.
- Недельная и месячная динамика; выручку, скидки и число сделок можно включать независимо.
- Сортируемая таблица менеджеров: выручка, число сделок, доля скидок и средний срок продажи.
- Кросс-фильтрация кликом по группе квартир, менеджеру и периоду. Повторный клик снимает отбор.
- Увеличение основной карты выделением области.

## Данные и запуск

Источник: «Продажи ЖК, март–сентябрь 2026.xlsx». Встроены 367 квартир, из них проданы 248. Отбор по менеджеру или дате сделки включает только проданные квартиры.

Откройте `index.html` в браузере. Данные, стили и скрипты включены в один файл; сборка и внешние библиотеки не требуются. GitHub Pages публикует корень ветки `main`.
